# 하드웨어 구조

부품 구성, 전원 설계, 장착 규약, 구매 체크리스트.

부품 선정의 수치적 근거(렌즈 초점거리, 모터 가속도 등)는 [physics.md](physics.md)에 있다.

관련 문서: [물리 계산](physics.md) · [피코 제어](pico-control.md) · [통신 프로토콜](protocol.md)

## 1. 전체 구성도

```
                      ┌──────────── 두뇌 계통 (5 V) ────────────┐
   [18650 UPS] ──5V──▶│                                         │
                      │  [라즈베리파이 5] ══PCIe══ [AI HAT+ 13T] │
                      │        ║  ║                  (Hailo-8L)  │
                      │     CSI║  ║USB                           │
                      │        ║  ║                              │
                      │  [GS 카메라]  [피코] ◀────────────────── │
                      └────────────────┬────────────────────────┘
                                       │ GPIO (PWM / 엔코더)
                      ┌────────────────┴──── 동력 계통 (11.1 V) ─┐
   [3S LiPo] ──11.1V─▶│  [PDB] ──▶ [BTS7960 ×3] ──▶ [모터 ×3]    │
                      └──────────────────────────────────────────┘
                                  ※ 접지(GND)는 두 계통 공통
```

## 2. 컴퓨팅

| 부품 | 역할 | 비고 |
|---|---|---|
| 라즈베리파이 5 | 영상 처리 + 궤적 추정 + 목표 속도 산출 | 8 GB 권장 |
| AI HAT+ 13TOPS (Hailo-8L) | YOLO 추론 가속 | PCIe로 파이5 연결 |
| 라즈베리파이 피코 | 모터 실시간 제어 전담 | 파이5와 USB CDC 연결 |

**왜 피코를 따로 두는가:** 리눅스는 실시간 OS가 아니라 1 kHz PID 루프의 주기를 보장할 수
없다. 스케줄러 지터가 수 ms 단위로 튄다. 피코는 인터럽트 없는 슈퍼루프로 1 ms 주기를
정확히 지킨다. 또 PIO 하드웨어로 엔코더를 CPU 개입 없이 카운트할 수 있다.

## 3. 센서

### 3.1 카메라

| 항목 | 사양 |
|---|---|
| 센서 | Sony IMX296 글로벌 셔터 |
| 해상도 | 1456 × 1088 |
| 픽셀 크기 | 3.45 µm |
| 프레임레이트 | 최대 60 fps (30 fps로 샘플링 사용) |
| 렌즈 | **8 mm** (C/CS 마운트) |
| 노출 | **0.29 ms 이하** |

렌즈 선정 근거는 [physics.md 5.1장](physics.md#51-렌즈-초점거리-트레이드오프).
글로벌 셔터가 필수인 이유는 [physics.md 5.2장](physics.md#52-노출과-모션-블러).

**장착 규약 (중요):**

- 로봇 **상단 중앙**에서 **수직 위**를 향하도록 장착
- 광학 중심을 로봇 회전 중심과 일치시킨다 — 어긋나면 로봇이 회전할 때 관측 좌표가 튄다
- 방향: **X_B(로봇 전방)가 이미지 +u, Y_B(좌측)가 이미지 −v** 를 향하도록 카메라를 돌려 고정
- 조립 후 틀어진 각도는 자로 맞추지 말고 `config.CAMERA_YAW_RAD`에 넣어 소프트웨어로
  보정한다 (훨씬 정확하다)

좌표계 정의와 변환식은 [pi5-algorithm.md 2장](pi5-algorithm.md#2-좌표계-정의).

### 3.2 엔코더

모터 내장 홀센서 엔코더 3개 (3.3 V, A/B 2상).

- 엔코더는 **기어박스 이전(모터축)**에 붙어 있다. 바퀴 회전수로 바꾸려면 기어비 34로 나눈다
- 오픈드레인인지 푸시풀인지 확인 필요 — 오픈드레인이면 풀업 저항이 필요하다
  ([pico-control.md 6장](pico-control.md#6-엔코더-pio))

## 4. 구동부

| 부품 | 수량 | 사양 |
|---|---|---|
| FIT0493 DC 기어드모터 | 3 | 12 V, 출력축 350 RPM, 기어비 34:1, 엔코더 내장 |
| BTS7960 모터드라이버 | 3 | 최대 43 A, RPWM/LPWM 방식 |
| 옴니휠 | 3 | 지름 100 mm |

**배치:** 120° 간격 삼각 배치 (3륜 홀로노믹 드라이브). 이론 장착각 90° / 210° / 330°,
중심-바퀴 거리 0.15 m.

**홀로노믹을 쓰는 이유:** 낙하 물체는 어느 방향으로든 떨어진다. 차동 구동이면 방향을 바꾸려
회전해야 하는데, 0.5초 안에 회전 + 직진을 다 할 시간이 없다. 옴니휠은 제자리에서 즉시
임의 방향으로 병진할 수 있다.

**조립 후 실측이 필수:** 장착각과 중심거리는 기구학 행렬에 직접 들어간다. 1~2° 틀어지면
직진 명령에 로봇이 비스듬히 간다. 자로 재고, 주행 테스트로 보정한다
([pico-control.md 10장](pico-control.md#10-브링업-절차)).

## 5. 전원 — 2계통 분리

| 계통 | 소스 | 공급 대상 |
|---|---|---|
| 두뇌 | 18650 UPS 5 V | 파이5 / AI HAT / 카메라 / 피코 |
| 동력 | 3S LiPo 11.1 V → PDB | 모터드라이버 3개 |

**왜 분리하는가:** 모터 기동 시 수 A의 돌입 전류가 흐른다. 같은 계통을 쓰면 전압이 순간
강하해 파이5가 브라운아웃으로 리셋된다. 3륜이 동시에 기동하는 이 시스템에서는 거의 확실히
발생한다.

**⚠ 접지는 반드시 공통으로 묶는다.** 피코의 PWM 신호와 드라이버의 기준 전위가 다르면 신호가
제대로 전달되지 않는다. 전원은 분리하되 GND는 한 점에서 만난다.

**LiPo 취급 주의:** 3S LiPo는 과방전(셀당 3.0 V 이하)되면 복구가 안 되고 부풀 수 있다.
저전압 알람 또는 BMS를 함께 쓴다.

## 6. 배선

핀 번호는 배선 확정 후 [`pico/config.h`](../pico/config.h)의 `MOTOR_PINS[3]`에 기록한다.
모터당 5핀이 필요하다.

| 신호 | 방향 | 설명 |
|---|---|---|
| `rpwm` | 피코 → 드라이버 | 정방향 PWM |
| `lpwm` | 피코 → 드라이버 | 역방향 PWM |
| `en` | 피코 → 드라이버 | R_EN / L_EN 공통 (상시 HIGH) |
| `enc_a` | 엔코더 → 피코 | A상 (PIO `in` 핀) |
| `enc_b` | 엔코더 → 피코 | B상 (PIO `jmp` 핀) |

**핀 배치 제약:**

- `rpwm`, `lpwm`은 PWM 슬라이스가 있는 핀이어야 한다. 피코는 8개 슬라이스 × 2채널이며,
  같은 슬라이스의 A/B 채널은 주파수를 공유한다. 모터 6개 PWM 채널이 서로 간섭하지 않게 배치
- `enc_a`, `enc_b`는 PIO가 접근 가능해야 하고, **같은 스테이트머신에서 쓰려면 인접**하는 것이
  안전하다
- 파이5 ↔ 피코는 **USB CDC**를 쓴다. 하드웨어 UART 핀이 아니다

## 7. 부품 체크리스트

구매 전 확인 항목이다.

### 확정

- [ ] 라즈베리파이 5 (8 GB)
- [ ] AI HAT+ 13TOPS (Hailo-8L)
- [ ] 라즈베리파이 피코
- [ ] 글로벌 셔터 카메라 (IMX296)
- [ ] **8 mm C/CS 마운트 렌즈** — 카메라에 기본 동봉되는 6 mm와 다를 수 있으니 별도 확인
- [ ] FIT0493 기어드모터 ×3
- [ ] BTS7960 모터드라이버 ×3
- [ ] 100 mm 옴니휠 ×3
- [ ] 18650 UPS 모듈
- [ ] 3S LiPo + 충전기 + 저전압 알람
- [ ] PDB (전원 분배 보드)

### 검토 필요

- [ ] **조명(LED)** — 노출 0.29 ms를 쓰려면 실내 조명으로 부족할 가능성이 높다
      ([physics.md 5.2장](physics.md#52-노출과-모션-블러))
- [ ] **섀시 재료** — 로봇 질량 3 kg 가정에 직접 영향. 가벼울수록 가속도가 좋아진다
      (a ∝ 1/m, [physics.md 2장](physics.md#2-진짜-제약은-가속도다))
- [ ] **통(쓰레기통) 본체** — 입구 지름 25 cm, 깊이는 튕겨나가지 않을 만큼
      (형상은 미결정, [open-questions.md](open-questions.md) 참고)
- [ ] 카메라 마운트 (로봇 중심 정렬용)
- [ ] 배선 재료 (점퍼, 커넥터, 열수축)

### 실험 소모품

- [ ] pet_bottle / can / paper_cup 샘플 (**각각 물이나 무게추로 100 g 이상 채워서 사용**)
- [ ] 투척 높이 2 m를 재현할 지그 또는 표시
