# LABA6_toyproject — 움직이는 쓰레기통

LABA6기 부트캠프 ToyProject: 사람이 던진 쓰레기의 낙하 궤적을 실시간으로 예측하고, 스스로 이동해서 받아내는 자율 쓰레기통을 만듭니다.

## 프로젝트 개요

- 카메라로 던져진 물체를 인식(YOLO)하고, 낙하 궤적을 물리 공식 + 칼만 필터로 예측
- 예측된 착지 지점으로 전방향(옴니/메카넘) 휠 베이스가 이동해 물체를 받아냄
- 목표 스펙: 일반 실내용 쓰레기통 기준, 가득 찼을 때 약 5kg까지 대응

## 시스템 구성

| 구분 | 구성 요소 |
|---|---|
| 제어 | Raspberry Pi 5, AI HAT(Hailo), IMX296 글로벌 셔터 카메라, Pico, UPS HAT(18650/21700) |
| 구동 | 모터(엔코더 포함), 옴니/메카넘 휠, 모터드라이버, 배터리 |
| 외관 | 쓰레기통 본체 |

### 하드웨어 연결 구조

![하드웨어 아키텍처]

> 범례: 파란선 = 신호 버스, 빨간선 = 전력 버스

**전원부**
- LiPo(3S, 18650/21700) + 저전압 알람 → 60A 퓨즈 → PDB(전원 분배 보드)
- PDB → VCC/GND OUT ×3 → 모터드라이버(BTS7960) D1·D2·D3 → 모터 M1·M2·M3
- UPS HAT(18650, 5V/5A) → Raspberry Pi 5 전원 공급 (예상 구동시간: 미정)

**제어부**
- Raspberry Pi 5
  - CSI 카메라 인터페이스(CAM0/CAM1) → AF-68(2MP) 카메라 모듈
  - GPIO/PCIe → AI HAT+ (Hailo)
  - USB-A ↔ USB-B, GND 공유로 Pico와 시리얼 연결
- Pico
  - GPIO(GPI0~GPI4)로 모터드라이버(BTS7960) ×3에 RPWM/LPWM/R_IS/L_IS/R_EN/L_EN 신호 전달
  - 모터 엔코더 피드백 수신 (엔코더 전원 배선 별도 구성)
  - PDB로부터 3.3V 전원 공급

**모터드라이버(BTS7960, ×3) 상세**
- 입력: RPWM, LPWM, R_IS, L_IS, R_EN, L_EN (Pico 신호)
- 출력: VCC(B+), GND(B-), OUT1, OUT2 → 모터 연결
- 모터(M) 측: EN-GND, EN-VCC, A상/B상 (엔코더 채널)


## 소프트웨어 파이프라인

1. **카메라 캡처**: Picamera2로 프레임 수집 (60fps, 짧은 노출로 블러 최소화)
2. **객체 탐지**: YOLOv8n (CPU 프로토타입 → Hailo `.hef` 변환 후 AI HAT에서 실행), 관심 클래스만 필터링 (사람 등은 제외)
3. **좌표 변환**: 카메라 캘리브레이션 + 물체 크기 기반 거리 추정으로 픽셀 → 실제 좌표(m) 변환
4. **궤적 예측**: 칼만 필터로 노이즈 보정 + 포물선 운동 공식으로 착지 시간/좌표 계산
5. **모션 제어**: 목표 좌표 → 이동 벡터(Vx, Vy, ω) → 역기구학 공식으로 바퀴별 속도 계산
6. **통신**: Pi → (USB 시리얼) → Arduino/Pico로 목표 속도 전달
7. **모터 제어**: Arduino/Pico에서 PWM 출력 + 인코더 피드백 기반 PID 속도 제어
